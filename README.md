# Collaborative-code-editor
A real-time collaborative code editor built using React, Monaco Editor, and modern web technologies. This project allows multiple users to write and edit code together in a shared environment.

#Features
  Real-time collaborative coding (UI ready)
  Monaco Editor integration (VS Code-like experience)
  Chat panel for communication
  File explorer and file management UI
  Language selection support
  Video call interface (UI)
  Modern UI with Tailwind CSS
